# SheSheild

SheSheild is a women safety application developed using Spring Boot.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Maven

## Features

- User registration and login
- Women safety features
- Emergency assistance
- User data management

## How to Run

1. Clone the repository.
2. Open the project in Eclipse or IntelliJ.
3. Configure the MySQL/Aiven database.
4. Update the database credentials.
5. Run the Spring Boot application.
